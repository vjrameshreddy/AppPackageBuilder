1 Overview

The Stale VEN Report Genaration Automation tool reads a PCE workload export CSV, identifies workloads whose VEN has not sent a heartbeat for 60 or more days, splits the results into Workstations (WK/UWK) and Servers, produces ready-to-import CSV batches that comply with PCE import limits, and saves a full console output log all in seconds, with no row-count restrictions.

Key benefit Replaces the manual VENs To Remove TEMPLATE.xlsx process no Excel required, no 400,000-row limit, fully reproducible results.
PropertyValue
Default stale threshold60 calendar days since last heartbeat
Workstation detectionHostname starts with WK or UWK (case-insensitive)
Import batch size limit999 rows per file (PCE max = 1,000 incl. header)
Unpair batch size limit500 VENs per operation (PCE VENs page limit)
PlatformWindows 10 / 11 (64-bit) : no Python required

3 Quick Start (5 Steps)

  • Export workloads from the PCE

    Log in to the Illumio PCE web console → Workloads (left menu) → Export (top-right) → Export all workloads. Save the downloaded CSV (typically workload_export.csv).

    ImportantNote the export date : you will use it as REPORT_DATE to lock the calculation.
  • Place the CSV in the working folder

    Copy workload_export.csv into the same folder as run_stale_ven_cli.bat.

  • Configure the batch launcher

    Right-click run_stale_ven_cli.bat → Edit. Update the four variables at the top:

    :: Path to the PCE workload export CSV
set INPUT_FILE=workload_export.csv

:: Heartbeat threshold in days (default: 60)
set DAYS=60

:: Base output directory
set BASE_DIR=%userprofile%\OneDrive - IBM\Documents\Stale_VEN_Cleanup_Gen_Reports

:: Date the PCE export was fetched : YYYY-MM-DD
:: Leave blank to use today's date.
set REPORT_DATE=2026-07-20

    Save and close Notepad.

  • Run the tool

    Double-click run_stale_ven_cli.bat : or right-click → Run as administrator if the output folder requires elevated permissions.

  • Verify and collect output files

    Read the console summary and verify the Check line adds up:

    Check: 22594 read - 2 skipped - 20978 active = 1614 stale

    If it does not add up, stop and investigate before proceeding to the PCE import. Open the dated sub-folder (e.g. VEN_Cleanup\20-July-2026\) to collect the output CSVs and log file.

4 Usage Guide: GUI and CLI

The same processing is available three ways. All three write identical files, so pick whichever suits you. Screenshots use anonymised demo data (export date 20-July-2026, 22,594 workloads, 1,614 stale).

LauncherBest forHow you give it settings
stale_ven_gui.exeInteractive use, previewing the stale list, trying a different thresholdA form in a window
run_stale_ven_cli.batThe usual repeat run: edit four variables once, then double-clickVariables at the top of the batch file
stale_ven_cli.exeScripts, scheduled tasks and quick one-off runsCommand-line options

A. Graphical interface (stale_ven_gui.exe)

Double-click stale_ven_gui.exe (or run python src\stale_ven_gui.py). No console window opens.

  1. Fill in the form. Browse to the original PCE workload export CSV; the status line turns green when it is valid. Set the stale threshold and the report date (the date the export was fetched, YYYY-MM-DD; Today fills in today). The line This run writes to shows the exact dated output folder.
  1. Advanced settings (optional). Tick Show advanced settings to change the workstation prefixes (default wk, uwk), the import batch size (1–999, default 999) and the TMP label (default TM-STALE_VEN). Reset to defaults restores them.
  1. Preview (optional). Click Preview to list the stale hosts without writing anything. Search by hostname or HREF and filter by All / Workstations / Servers.
  1. Run. Click Run. The Log tab shows the same text the command-line tool prints, and the same run_log_<date>.txt is saved in the output folder. Tick Dry run first to count and list the files without creating any folder or file.
  1. Review the results. The Results tab shows the counts and the files written. Open output folder opens the dated folder; Export summary… saves a plain-text report of the run.

The window remembers the input file, threshold, output folder and advanced settings between sessions in %APPDATA%\StaleVENReportGen\settings.json. The report date and the dry-run box are deliberately not remembered.

B. Batch launcher (run_stale_ven_cli.bat)

Edit INPUT_FILE, DAYS, BASE_DIR and REPORT_DATE at the top of the file, then double-click it. It creates the dated folder, writes the launcher banner to the run log and runs stale_ven_cli.exe (or the Python script if the exe is missing).

C. Command line (stale_ven_cli.exe)

Run it from Command Prompt or PowerShell. The batch file uses exactly these options, so anything it does you can do directly:

stale_ven_cli.exe workload_export.csv --report-date 2026-07-20 --out-dir Reports\20-July-2026

5 How It Works

Processing flow

1 : Read all rowsParses the PCE workload export CSV. No row-count limit.
2 : Classify each rowParses last_heartbeat_on. Skips rows with blank/null heartbeat or blank/"0" hostname. Computes elapsed = report-date − heartbeat date (calendar days). Marks as STALE if elapsed ≥ threshold.
3 : Split stale rowsHostname starts with WK or UWK (case-insensitive) → Workstations. Everything else → Servers.
4 : Write master listsFull list without row limits: master-list_workstations_DD-Month-YYYY.csv and master-list_servers_DD-Month-YYYY.csv.
5 : Write PCE-import batchesEach group is split into files of max 999 rows, ready for PCE Workloads import.
6 : Print summaryDisplays totals, file names with row counts, and the number of PCE unpair operations required.
7 : Save run logFull console output written to run_log_DD-Month-YYYY.txt in the output directory.

Day-count logic : matches Excel exactly

The tool uses date-only comparison (calendar days), identical to Excel's TODAY():

elapsed = report-date − heartbeat date   (time-of-day is ignored)

A heartbeat of 2026-05-21T23:59:59Z with a report date of 2026-07-20 counts as 60 days stale : not 59.

Report date : reproducible results

ScenarioWhat to set
Running on the same day as the exportLeave REPORT_DATE blank (uses today)
Re-running days or weeks later against the same CSVSet REPORT_DATE=YYYY-MM-DD to the original export date
Generating a report for a specific past snapshotSet REPORT_DATE to that snapshot's date
WarningWithout --report-date, the stale count increases every day as more heartbeats age out. Use it to lock results to the export date and ensure they are fully reproducible.

Hostname exclusion rules

Rows with a blank hostname or hostname exactly "0" are skipped and counted in the Skipped total shown in the console.

7 PCE Import Procedure

Step 1 : UPS Validation

  • Raise a P3 ServiceNow ticket.

  • Attach master-list_workstations_20-July-2026.csv and master-list_servers_20-July-2026.csv.

  • UPS will review and share a final validated list.

  • Cross-check the validated list against the import batches before proceeding.

Step 2 : Label stale workloads via CSV import

  • Open the PCE web console → navigate to Workloads.

  • Click Import (top-right).

  • Upload workstations_20-July-2026_batch_01.csv → confirm the import.

  • Repeat for every _batch_XX.csv file (workstations first, then servers), one file at a time.

  • After each import, verify that the label TM-STALE_VEN has been applied to the workloads.

Limit: 999 data rows per import filePCE enforces a maximum of 1,000 lines including the header row. Verify HREF values are correct before each import : do not import if HREFs look wrong.

Step 3 : Unpair the stale VENs

  • In the PCE web console, navigate to VENs.

  • Filter by label TM-STALE_VEN.

  • Select up to 500 VENs → click Unpair.

  • Repeat until all stale VENs are unpaired. The tool prints the required number of operations at the end of its run (e.g. 4 unpair operation(s) needed for 1,614 VENs → 500 + 500 + 500 + 114).

8 Command-Line Reference

The tool can be run directly from a Command Prompt or PowerShell window without the batch file.

Syntax

stale_ven_cli.exe <input.csv> [--days N] [--out-dir PATH] [--report-date YYYY-MM-DD]
python src/stale_ven_cli.py  <input.csv> [--days N] [--out-dir PATH] [--report-date YYYY-MM-DD]

Arguments

ArgumentRequiredDefaultDescription
inputYes:Path to the PCE workload export CSV
--daysNo60Heartbeat threshold in days
--out-dirNoven_outputOutput directory for all CSV files
--report-dateNoTodayDate the PCE export was fetched (YYYY-MM-DD) : locks elapsed-day calculation and filenames

Examples

::  Default : 60-day threshold, reference date = today
stale_ven_cli.exe workload_export.csv

::  Reproduce results for an export taken on 20-Jul-2026
stale_ven_cli.exe workload_export.csv --report-date 2026-07-20

::  Custom threshold : 90 days
stale_ven_cli.exe workload_export.csv --days 90 --report-date 2026-07-20

::  Specific output folder
stale_ven_cli.exe workload_export.csv --report-date 2026-07-20 --out-dir "C:\VEN_Cleanup\20-July-2026"

::  Pipe output to a log file
stale_ven_cli.exe workload_export.csv --report-date 2026-07-20 > run.log 2>&1

10 Excel Template vs This Tool

Excel Template

  • ~400,000 row limit
  • Slow (formula recalculation)
  • Manual blank hostname filter
  • Manual workstation/server split
  • Manual copy-paste for PCE batches
  • Manual unpair count calculation
  • TODAY() : not reproducible
  • No console log
  • Requires Microsoft Excel

Stale VEN Report Genaration Automation

  • Unlimited rows
  • Seconds to complete
  • Automatic blank hostname exclusion
  • Automatic workstation/server split
  • Automatic PCE import batching (999 rows/file)
  • Unpair count printed in summary
  • Reproducible via --report-date
  • Run log auto-saved to output folder
  • Standalone exe : no dependencies

Day-count accuracy is identical to Excel in both cases : calendar-day comparison, time-of-day ignored.
